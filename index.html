Topic 1: Variation

Lesson

Variation describes the relationship between two or more quantities. The value of one quantity may depend on the value of another quantity.

There are three important types of variation:

  • Direct variation
  • Inverse variation
  • Joint variation

Direct Variation

If y varies directly as x, we write:

y ∝ x

Therefore:

y = kx

where k is the constant of variation.

Inverse Variation

If y varies inversely as x, then:

y ∝ 1/x

Therefore:

y = k/x

Joint Variation

If y varies jointly as x and z:

y ∝ xz

Therefore:

y = kxz

Worked Examples

Example 1

y varies directly as x. If y = 12 when x = 4, find y when x = 10.

y = kx

12 = 4k

k = 3

Therefore y = 3x.

When x = 10:

y = 3 × 10 = 30

Example 2

y varies inversely as x. If y = 8 when x = 3, find y when x = 12.

y = k/x

8 = k/3

k = 24

Therefore y = 24/x.

When x = 12:

y = 24/12 = 2

Practice Questions

1. If y varies directly as x and y = 20 when x = 5, find y when x = 8.
2. If y varies inversely as x and y = 6 when x = 4, find y when x = 8.
3. If y = kxz, find k when y = 30, x = 3 and z = 5.

Answers

1. 32
2. 3
3. 2

Topic 2: Sequence and Series

Lesson

A sequence is an ordered list of numbers arranged according to a particular rule.

Example:

2, 4, 6, 8, 10, ...

A series is the sum of the terms of a sequence.

Arithmetic Progression

An arithmetic progression (AP) is a sequence in which the difference between consecutive terms is constant.

The nth term is:

Tₙ = a + (n - 1)d

where:

  • a = first term
  • d = common difference
  • n = number of terms

The sum of n terms is:

Sₙ = n/2 [2a + (n - 1)d]

Geometric Progression

A geometric progression (GP) is a sequence in which consecutive terms have a constant ratio.

The nth term is:

Tₙ = arⁿ⁻¹

where r is the common ratio.

Worked Examples

Example 1

Find the 10th term of the AP: 3, 7, 11, 15, ...

a = 3

d = 7 - 3 = 4

T₁₀ = 3 + (10 - 1)4

= 3 + 36

= 39

Example 2

Find the sum of the first 10 terms of: 2, 5, 8, 11, ...

a = 2, d = 3, n = 10

S₁₀ = 10/2 [2(2) + (10 - 1)(3)]

= 5[4 + 27]

= 5 × 31

= 155

Practice Questions

1. Find the 8th term of the AP: 5, 9, 13, 17, ...
2. Find the 10th term of the AP: 4, 7, 10, 13, ...
3. Find the sum of the first 10 terms of: 2, 4, 6, 8, ...

Answers

1. 33
2. 31
3. 110

Topic 3: Quadratic Equations

Lesson

A quadratic equation is an equation that can be written in the form:

ax² + bx + c = 0

where a, b and c are constants and a ≠ 0.

Methods of Solving Quadratic Equations

Quadratic equations can be solved by:

  • Factorization
  • Completing the square
  • Quadratic formula

Quadratic Formula

For:

ax² + bx + c = 0

the solutions are:

x = (-b ± √(b² - 4ac)) / 2a

The expression:

b² - 4ac

is called the discriminant.

Worked Examples

Example 1

Solve:

x² - 5x + 6 = 0

Factorize:

(x - 2)(x - 3) = 0

Therefore:

x = 2 or x = 3

Answer: x = 2, 3

Example 2

Solve:

x² + 2x - 8 = 0

Factorize:

(x + 4)(x - 2) = 0

Therefore:

x = -4 or x = 2

Answer: x = -4, 2

Practice Questions

1. Solve: x² - 7x + 12 = 0
2. Solve: x² + x - 6 = 0
3. Solve: x² - 9 = 0

Answers

1. x = 3 or 4
2. x = 2 or -3
3. x = 3 or -3
